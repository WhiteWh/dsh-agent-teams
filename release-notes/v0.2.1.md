# AgentTeams v0.2.1

A panel-visual release on top of 0.2.0, requested by the owner after living with the tree:
**work is now the node's own height instead of a small icon inside its text.**

- **A full-node work plaque in the members tree.** The compact animated six-dot mark said
  "something is running" without being part of the node it described, so it is gone from a
  member row. In its place a plaque three dots wide runs down the right edge of the row over
  its full height, and its dots pulse in a top-to-bottom wave while that member works. When
  the member is idle the column stays as a faint slot marker, so the lit wave — not the
  column — is what reads as work.
- The text state next to it (`Working`, `Ready to continue`, `Delivered`, …) is unchanged and
  remains the accessible answer; the compact glyph still marks the captain node and the
  collapsed panel pill, where no full-height node exists.
- The plaque colours itself with the same business-primary token as the rest of the busy
  surfaces, so it follows the theme, and it animates inside the existing
  `prefers-reduced-motion` handling.

## Compatibility

No state, tool, schema or gate changed: this release ships the client bundle only. A stored
`team.json`, a profile and every tool call behave exactly as in 0.2.0, and the supported
Harness matrix is unchanged (recommended `0.1.5-rc.1`).

```sh
dsh plugin --profile <your-profile> add --save-exact @nanmicoder/dsh-agent-teams@0.2.1
```

Then restart Harness and refresh the page — a browser that already has the panel open keeps
the old bundle until it reloads.

See [release verification](https://github.com/WhiteWh/dsh-agent-teams/tree/agent-teams-hardening/docs/releases/v0.2.1) for the verification matrix, the artifact digest and the deployment record.
